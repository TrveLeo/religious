Devocional Diário

O que este app armazena

O Devocional Diário usa a API do Instagram (Meta) para publicar conteúdo no perfil do projeto e para responder automaticamente a comentários com palavras como "amém".

Dados de usuários do Instagram que o app acessa:

  • Texto de comentários: processado em memória apenas para identificar a palavra-gatilho ("amém" e variações). Não é armazenado.
  • ID do comentário: usado temporariamente para postar a resposta automática via API. Não é armazenado.
  • Métricas de posts: alcance, curtidas e visualizações dos próprios posts do projeto (dados agregados, sem identificação individual). Armazenados em arquivos locais para análise de desempenho interno.

O app não armazena nome, foto de perfil, e-mail, localização nem nenhuma outra informação pessoal de usuários do Instagram.

Como solicitar exclusão de dados

Como não armazenamos dados pessoais identificáveis de usuários, não há dados a excluir. Mesmo assim, se você quiser confirmar que nenhum dado seu está armazenado ou solicitar uma verificação formal, siga os passos abaixo:

  1. Envie um e-mail para diariod777@gmail.com com o assunto "Solicitação de exclusão de dados".
  2. Informe o nome de usuário do Instagram associado à solicitação.
  3. Responderemos em até 30 dias confirmando que nenhum dado pessoal seu está armazenado, ou detalhando quais dados foram encontrados e como foram excluídos.

Desconectar o app do Instagram

Se você autorizou este app a acessar sua conta do Instagram e deseja revogar esse acesso:

  1. Acesse Instagram → Configurações → Segurança → Apps e sites.
  2. Localize o app Devocional Diário e clique em Remover.

Ao remover o acesso, o app não conseguirá mais ler comentários nem publicar conteúdo em seu nome. Como não armazenamos seus dados, não há nenhuma informação residual a excluir após a revogação.
