Política de Privacidade

Devocional Diário

O que este site e este perfil fazem

O Devocional Diário é um projeto pessoal, sem fins comerciais, que publica conteúdo bíblico (versículos, devocionais e jogos) em um site estático e em um perfil do Instagram. Não coletamos cadastro, login ou dados pessoais de visitantes do site.

Integração com o Instagram (API da Meta)

Usamos a API do Instagram (Meta) exclusivamente para:

  • Publicar conteúdo automaticamente no perfil do projeto (imagens, carrosséis e reels).
  • Ler notificações de novos comentários via webhook para identificar comentários com palavras como "amém" e enviar uma resposta automática de agradecimento.
  • Coletar métricas de alcance e engajamento dos próprios posts (insights), para uso interno de análise de desempenho.

Dados acessados: texto do comentário (processado em memória apenas para verificar a presença da palavra-gatilho), ID do comentário (usado para postar a resposta) e métricas agregadas dos posts (alcance, curtidas, visualizações).

Retenção: o texto dos comentários não é armazenado em nenhum banco de dados. O processamento ocorre em memória no momento do recebimento do webhook e o dado é descartado imediatamente. As métricas de insights são armazenadas localmente em arquivos JSON no repositório do projeto, sem identificação de usuários individuais.

Compartilhamento: nenhum dado é vendido, compartilhado ou transferido a terceiros para fins comerciais.

Infraestrutura e terceiros

O webhook de resposta automática a comentários é executado via Cloudflare Workers (Cloudflare, Inc.). O código processa o evento recebido e faz a chamada à API da Meta para postar a resposta. Nenhum dado do evento é armazenado pelo worker. A política de privacidade da Cloudflare está disponível em cloudflare.com/privacypolicy.

O site é hospedado via GitHub Pages (GitHub, Inc. / Microsoft). Nenhum dado de visitantes é coletado pelo projeto nessa camada.

Cookies e rastreamento

Este site não usa cookies, não possui sistema de login e não realiza rastreamento de visitantes.

Exclusão de dados

Como não armazenamos dados pessoais de usuários do Instagram, não há dados a excluir.
